Names come from Voicemeeter Macro Buttons. After renaming a button there, press refresh to update the list.

Toggle flips the button on each press. Push holds it on while the key is held.

Toggle mode only. Pressing the key still toggles the button straight away. If you hold it for at least this many milliseconds (1000 = 1 second), releasing it toggles the button back.

Set the title, its position and the icon for each state (Off and On) in the settings above, like any other action.
